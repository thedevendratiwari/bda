# Problem Statement: Railway Operations and Train Delay Analytics

A railway zone operates 200 trains and records information about approximately 30,000 train trips over a 9-month period. The railway authority maintains train details such as train type, zone, distance, number of coaches, train age, and previous breakdowns. Each trip record contains the trip date, weather condition, maintenance activity, passenger count, and actual delay in minutes.

The railway management wants to use Apache Spark to analyze operational performance and predict train delays.

// Requirements

1. Load the train and trip datasets into PySpark DataFrames.

2. Use Spark SQL to analyze:

   * Train distribution by railway zone.
   * Average delay and delay percentage based on weather.
   * Delay performance by train type.

3. Use Spark Window Functions to:

   * Identify the top 3 delay-prone trains in each zone.
   * Calculate monthly total delay, running total of delays, month-over-month change, and 3-month moving average.

4. Perform data analysis to identify the impact of:

   * Weather conditions.
   * Track maintenance.
   * Train age.
   * Railway zone

   on train delays.

5. Build MLlib classification models to predict whether a trip will be delayed by more than 15 minutes:

   * Logistic Regression.
   * Random Forest.
   * Compare their performance using AUC.

6. Build a basic neural network using Multilayer Perceptron and compare its performance with the MLlib models.

7. Store the train data, trip data, and prediction results in PostgreSQL using Spark JDBC.

8. Read the PostgreSQL data back into Spark and identify high-risk trips having a high probability of delay.

9. Execute the Spark analytics and ML workflow on a cloud Spark platform such as Databricks.

10. Study how autoscaling, cluster sizing, auto-termination, and cloud storage formats can be used to reduce Spark processing cost.

// Expected Outcome

The final system should provide:

* Railway operational and delay analysis.
* Top delay-prone trains and zones.
* Factors contributing to delays.
* A model that predicts whether a train trip will be delayed.
* Prediction results stored in PostgreSQL.
* A cloud-based Spark execution of the same analytics workflow.


WSL + Java 17 + PySpark 3.5.1 + PostgreSQL setup.

python
import numpy as np
import pandas as pd

np.random.seed(42)

# --
# TRAIN MASTER DATA
# --
n = 200

trains = pd.DataFrame({
    "train_id": range(1, n + 1),
    "train_type": np.random.choice(
        ["Rajdhani", "Superfast", "Express", "Passenger"], n
    ),
    "zone": np.random.choice(
        ["Southern", "Western", "Northern", "Eastern", "Central"], n
    ),
    "distance_km": np.random.randint(100, 2200, n),
    "coaches": np.random.randint(8, 24, n),
    "age_years": np.random.randint(1, 30, n),
    "prior_breakdowns": np.random.poisson(1, n)
})

trains.to_csv("data/trains.csv", index=False)

# TRIP DATA
m = 30000

trips = pd.DataFrame({
    "trip_id": range(1, m + 1),

    "train_id": np.random.randint(1, n + 1, m),

    "trip_date": (
        pd.to_datetime("2026-01-01")
        + pd.to_timedelta(
            np.random.randint(0, 270, m),
            unit="D"
        )
    ).strftime("%Y-%m-%d"),

    "weather": np.random.choice(
        ["Clear", "Rain", "Fog"],
        m,
        p=[0.60, 0.25, 0.15]
    ),

    "maintenance_block": np.random.choice(
        [0, 1],
        m,
        p=[0.85, 0.15]
    ),

    "passengers": np.random.randint(200, 1800, m)
})

# CREATE DELAY PATTERN
t = trips.merge(
    trains,
    on="train_id",
    how="left"
)

z = (
    -3.0
    + 1.0 * (t.weather == "Fog")
    + 0.5 * (t.weather == "Rain")
    + 0.9 * t.maintenance_block
    + 0.04 * t.age_years
    + 0.3 * t.prior_breakdowns
    + 0.0005 * t.distance_km
)

late = np.random.rand(m) < (
    1 / (1 + np.exp(-z))
)

trips["delay_minutes"] = np.where(
    late,
    16 + np.random.exponential(30, m).round(0),
    np.random.randint(0, 16, m)
).astype(int)

trips.to_csv("data/trips.csv", index=False)

print(
    "Done:",
    len(trains),
    "trains,",
    len(trips),
    "trips"
)

# PART 11 — Spark SQL Queries

// Query 1 — Fleet profile by zone
spark.sql("""
SELECT
    zone,
    COUNT(*) AS trains,
    ROUND(AVG(age_years),1) AS avg_age,
    ROUND(AVG(distance_km),0) AS avg_distance_km
FROM trains
GROUP BY zone
ORDER BY trains DESC
""").show()


// Query 2 — Delay by weather

spark.sql("""
SELECT
    weather,
    COUNT(*) AS trips,
    ROUND(AVG(delay_minutes),1) AS avg_delay_min,
    ROUND(AVG(delayed)*100,1) AS delayed_pct
FROM trips
GROUP BY weather
ORDER BY delayed_pct DESC
""").show()




// Query 3 — Delay by train type
spark.sql("""
SELECT
    tr.train_type,
    COUNT(*) AS trips,
    ROUND(AVG(t.delay_minutes),1) AS avg_delay_min,
    ROUND(AVG(t.delayed)*100,1) AS delayed_pct
FROM trips t
JOIN trains tr
ON t.train_id = tr.train_id
GROUP BY tr.train_type
ORDER BY delayed_pct DESC
""").show()

# SESSION 29 — WINDOW FUNCTIONS

# PART 13 — Ranking Trains

Run:

spark.sql("""
WITH train_delay AS (
    SELECT
        tr.train_id,
        tr.train_type,
        tr.zone,
        ROUND(SUM(t.delay_minutes)/60,0) AS total_delay_hrs
    FROM trips t
    JOIN trains tr
    ON t.train_id = tr.train_id
    GROUP BY
        tr.train_id,
        tr.train_type,
        tr.zone
)

SELECT *
FROM (
    SELECT
        *,
        ROW_NUMBER() OVER (
            PARTITION BY zone
            ORDER BY total_delay_hrs DESC
        ) AS row_num,

        RANK() OVER (
            PARTITION BY zone
            ORDER BY total_delay_hrs DESC
        ) AS rnk,

        DENSE_RANK() OVER (
            PARTITION BY zone
            ORDER BY total_delay_hrs DESC
        ) AS dense_rnk

    FROM train_delay
)
WHERE rnk <= 3
ORDER BY zone, rnk
""").show(15)


//Result:


Top 3 delay-prone trains in every zone

# PART 14 — Running Total
spark.sql("""
WITH monthly AS (
    SELECT
        date_format(trip_date,'yyyy-MM') AS month,
        ROUND(SUM(delay_minutes)/60,0) AS delay_hours
    FROM trips
    GROUP BY 1
)

SELECT
    month,
    delay_hours,

    SUM(delay_hours) OVER (
        ORDER BY month
    ) AS running_total_hrs,

    delay_hours -
    LAG(delay_hours,1) OVER (
        ORDER BY month
    ) AS change_vs_prev_month,

    ROUND(
        AVG(delay_hours) OVER (
            ORDER BY month
            ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
        ),
        0
    ) AS moving_avg_3m

FROM monthly
ORDER BY month
""").show()

# PART 17 — Prepare ML Dataset

python
df = (
    trips
    .join(trains, "train_id")
    .withColumn(
        "weather_score",
        F.when(F.col("weather") == "Fog", 2)
         .when(F.col("weather") == "Rain", 1)
         .otherwise(0)
    )
    .withColumn(
        "label",
        F.col("delayed").cast("double")
    )
)


//Features:
features = [
    "distance_km",
    "coaches",
    "age_years",
    "prior_breakdowns",
    "passengers",
    "maintenance_block",
    "weather_score"
]


//Split:
train, test = df.randomSplit(
    [0.8, 0.2],
    seed=42
)


//Check:
print("Train:", train.count())
print("Test :", test.count())




# PART 18 — VectorAssembler
assembler = VectorAssembler(
    inputCols=features,
    outputCol="raw"
)


# PART 19 — StandardScaler

scaler = StandardScaler(
    inputCol="raw",
    outputCol="features",
    withMean=True,
    withStd=True
)




# PART 20 — AUC Evaluator

python
auc_eval = BinaryClassificationEvaluator(
    labelCol="label",
    metricName="areaUnderROC"
)




# PART 21 — Logistic Regression

Create model:

python
lr_model = Pipeline(
    stages=[
        assembler,
        scaler,
        LogisticRegression(labelCol="label")
    ]
).fit(train)


Predict:

python
lr_pred = lr_model.transform(test)


Evaluate:

python
print(
    "Logistic Regression AUC:",
    round(auc_eval.evaluate(lr_pred), 3)
)
